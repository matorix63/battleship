# Battleship

The final project of The Odin Project's JavaScript course

## Play

You and the computer each get a random fleet of five ships. Click enemy waters to fire; the computer answers. Sink the whole fleet to win. "Randomize fleet" button feshuffles your ships until the first shot is fired.

## TDD

The game logic was written test-first using Jest.
